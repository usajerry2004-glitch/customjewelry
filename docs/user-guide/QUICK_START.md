# Kira Custom Jewelry — Quick Start Guide

## For Sales Reps

### Creating a New Custom Order
1. Click **+ New Order** button (top right)
2. Enter customer and store information
3. Specify: Type, Size, Metal Type, Metal Color, Diamond Quality, Stone Shape
4. Attach reference images or web links
5. Submit → Order enters **Waiting Confirmation** status

## For Authorizers

### Reviewing & Approving Orders
1. Filter orders by **Waiting Confirmation**
2. Review all details including customer notes
3. **Approve** → moves to CAD queue
4. **Reject** → notifies sales rep with reason

### Approving CAD Files
1. Find orders in **CAD sent to customer** stage
2. View the CAD render and cost estimate
3. **Approve** → moves to SKU Creation
4. **Request Revision** → back to CAD team with notes

## For CAD Designers

1. Dashboard shows your **Pending CAD** queue
2. Download order specs and reference images
3. Upload completed 3DM file + preview render
4. Set estimate cost
5. Click **Send to Customer** → auto-emails client

## For Factory Managers

1. See all **VPO Issued** orders for your factory
2. Update production status at each stage
3. Request stones from USA office if needed
4. Mark **Complete** when piece is ready to ship

## For Stone Managers

1. Receive alerts for new stone requests
2. Check inventory availability
3. Mark as **Allocated** when confirmed
4. Update to **Shipped to Factory** when dispatched

## For US Setters

1. View orders assigned to you for setting/repair
2. Confirm receipt when piece arrives
3. Update notes as work progresses
4. Mark **Delivered** after handoff to customer

## Status Glossary

| Status | Meaning |
|--------|---------|
| Waiting Confirmation | Pending authorizer review |
| Pending CAD | Approved, in CAD queue |
| VPO Issued | Purchase order sent to factory |
| Ready to Invoice | Factory done, invoice pending |
| Ready to Ship | Cleared to ship to USA |
| Repair | US setter has for finishing |
| Delivered | Order complete |
